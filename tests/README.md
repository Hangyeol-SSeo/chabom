# 테스트 데이터 원칙

이 디렉터리는 합성 데이터만 사용합니다. 실제 조회 결과를 복사하지 않습니다.

- 매물·사진·기록부 URL은 `example.com` 또는 그 하위 도메인을 사용합니다.
- 차량번호는 `00가0000`처럼 할당된 차량을 가리키지 않는 형식 검사용 값만 사용합니다.
- 연락처는 가운데 네 자리가 0000인 명시적 테스트 값을 사용합니다.
- 이름·상사·주소·판매자 ID에는 테스트/가상 표기를 사용합니다.
- 보험금과 주행거리 등 수치는 파싱·판정 경계 검증에 필요한 합성 값입니다.
- 실제 조회·찜·블랙리스트 데이터는 Git에서 제외된 `data/`에만 보관합니다.

`test_fixture_privacy.py`는 연락처·차량번호·URL 규칙을 검사합니다.
